## Notes
- Standard pipeline: vLLM `--reasoning-parser qwen3` separates `<think>` into `reasoning_content`; scorers see only post-think `content`. ChartQA uses LMMs-Eval `relaxed_correctness`; CharXiv/ChartMuseum use Qwen3.6-27B judge (3-host vLLM, enable_thinking=False, official rubrics verbatim).
- Old baseline pipeline: thinking on with `<answer>` regex extraction, custom relaxed scorer (more lenient unit handling).
- `mode` column shows the most-frequently-best mode across the 5 benches for each model.
- `--` indicates the scored file is missing (e.g., judge phase still in flight).
